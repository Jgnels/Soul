# Production push tools

These tools operate on the opt-in 3.5 km composition candidate. They do not promote it, change the default map, or activate SoulWorldTerrain/SoulCampaignExpansion.

## Runtime

`qualify_runtime.py input --run NAME` uses existing ordinary keyboard/mouse/controller/recruitment/F5/F9 proof.

`qualify_runtime.py load --run NAME --source Evidence/ProductionPush-20261008/Local/INPUT_RUN` copies the real isolated F5 slot and its independently recorded expected snapshot, then runs existing fresh-process F9 verification.

`qualify_runtime.py authored --run NAME` uses the existing Human authored proof, including two-domain construction restoration, visit/return, physical battle and return. On this machine the intact uncooked city requires long loads; do not repeatedly rerun it for unrelated road art.

`qualify_runtime.py traversal --run NAME` observes forty continuous legal moves through normal clicks and end-day input. It never teleports, changes ownership, or bypasses action points. Two physical ferry passages are shared by seven legal pairs. Walking figures are hidden only over those saved ferry segments. This is a provisional strategic ferry transition, not a boat simulation.

`qualify_runtime.py recovery --run NAME` invokes the pre-existing explicit defeat/recruit/retry qualification with small player forces. It does not alter normal scenario data or battle rules.

`qualify_runtime.py profile --run NAME` is the single uncapped native 1080p campaign measurement. Do not run it before functional/visual review. Existing 85 C guard is unchanged. Other rendered qualification modes are capped at20 FPS.

`run_native.py --run NAME [--composition]` runs existing CampaignWorld native automation against the current editor binary.

Run only one UE/build process at a time. Run names are immutable evidence directories; reruns need a new name. Process exit alone is not acceptance. Inspect receipts and screenshots.

## Content and preservation

The frozen Landscape PNG is serialized losslessly to R16 for the existing height-query adapter; it is not rebaked. Owned visual derivatives and large evidence stay local under the established ignore rules.

`finish_bridge.py` adds one bounded, collision-free cosmetic masonry pass. It must be run only once in the loaded candidate and visually reviewed. It does not change the qualified timber travel lane.

`capture_final.py` captures fixed native Unreal review views. `make_gallery.py` links actual prior/current screenshots. No generated imagery is used.

`verify_preservation.py` compares baseline donor/reference hashes and inherited dirty files. Only the candidate map and the explicitly recorded runtime-source delta are intentional changes among those baseline files. New assets are listed separately.
