# Authored settlement tools

These tools extend the existing Soul settlement, campaign and RBSave authorities. They do not own construction, economy, battle outcomes or saved state. Donor maps/packages are read-only inputs. Generated maps/meshes are local licensed derivatives and are not included in source commits.

Run live-editor scripts in a temporary Python namespace, for example `exec(open(path).read(), {...inputs...})`. Do not retain lists of actors/worlds across map loads. A timed-out Nwiro request can still execute later; inspect its log/receipt before retrying. Run only one UE/build process and preserve the 85 C cutoff.

- `snapshot_donor.py`: inventories family files, hashes every map/external package and records size/mtime for other content. Compare the complete `files` arrays before claiming preservation.
- `survey_loaded_environment.py`, `inspect_human_wrapper.py`: read-only actor/native-instance surveys. Presence is not rendered acceptance.
- `create_owned_variant.py`: one guarded Save As of the inspected source map; reloads the owned destination before any later edits. Does not duplicate every referenced mesh/material/sublevel.
- `prepare_dwarven_variant.py`, `author_dwarven_groups.py`, `prepare_dwarven_lighting.py`: scoped owned-Citadel authoring. Existing destinations/receipts intentionally fail rather than overwrite qualified work. Separate mutation receipts record later candle-reference and flame-card corrections.
- `export_dwarven_miniature_source.py`, `build_dwarven_renderlod_miniature.py`: deterministic source-transform/lowest-render-LOD derivation. Whole-city cutaway trials were visually rejected. The r5 hall cutaway only proves matching state; it is not accepted final capital art. Do not rerun the older rejected all-at-once actor-merge experiment.
- `author_dwarven_scenario.py`: creates the nonvisual opt-in binding from the JSON recipe. The existing saved DA should be inspected, not recreated over itself.
- `qualify_dwarven_approach.py`: initial deployment-only collision survey. It **does not test reserve entries**.
- `qualify_dwarven_entries.py`: exact existing reserve corridor geometry checks. Static clearance still requires actual battle proof, including enemy-distance scoring, arrivals and return.
- `qualify_authored.py functional --run UNIQUE`: isolated actual-input construction/visit/F5/F9/battle sequence. The native observer emits explicit checks; the launcher additionally requires actual reserve arrivals on both sides for this fixed fixture. Inspect the screenshots separately.
- `qualify_authored.py fresh-performance ...`: fresh process using a copied isolated evidence checkpoint and independently supplied expected domains. Both 20-second warmups and 30-second samples are uncapped at actual 1920×1080; loading/travel is capped at 20 FPS for thermal safety.
- `summarize_authored_profile.py`: joins native raw-frame reports to sampled process/GPU telemetry. GPU allocation is device-wide; fixed-view editor-game numbers are not a cooked/full-world performance claim.
- `mount_complete_human_source.ps1`: already executed once for Jeff's complete supplied Medieval Kingdom source. Preserves prior junctions outside Content. It refuses a second run; no further source recovery/download is needed.

Use `Evidence/SettlementEnvironmentPlan-20261005/Continuation-20261006/` for concise receipts and `Local/` for large logs, captures, saved-game checkpoints and payload backups. The current handoff and rendered review supersede older provisional receipts; never edit an old failed-run receipt into a pass.
