# Soul

Soul is a PC-first Unreal Engine 5.8 fantasy strategy game from RefinedBadger Studios.

Current foundation direction:
- living 3D adventure map;
- deterministic hidden-hex turn-based tactical battles;
- initiative timeline with wait/defend/retaliation;
- persistent commander memory;
- persistent regiment veterancy;
- finite recruitment growth;
- geography-driven battlefield selection;
- layered, prepared sieges;
- full-sized 3D units and Paragon-scale heroes;
- RB-first Unreal foundation.

The project was started clean in Unreal. Living Strategy/Godot is a project-owned donor/reference implementation, not a runtime dependency.
